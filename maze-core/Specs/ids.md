# IDs

## Purpose

Shared identity primitives used across all modules. Extracted to break circular dependencies between `graph` and `space`.

## Types

### NodeId

`u64` — unique identifier for a node in a Graph. Generated by `IdGenerator`, not derived from position or geometry. Multiple fields in the same session share one generator — NodeIds are globally unique within a session.

### EdgeId

`usize` — index into the `Graph::edges` vector. Stable after creation: removal uses tombstone (not swap-remove), so EdgeId never changes after assignment.

### IdGenerator

Sequential counter starting at 0. Single source of NodeId generation. Passed by `&mut` to `StandardField::new` so multiple fields share one namespace.

```rust
IdGenerator::new() -> Self       // starts at 0
generator.next_id() -> NodeId   // returns current, increments
```

Implements `Default` (delegates to `new()`).

## Invariants

- NodeId values are sequential but callers must not rely on order or gaps.
- EdgeId is a direct index — valid as long as the Graph exists and the edge has not been removed.
- IdGenerator is not thread-safe — single-threaded use only.
