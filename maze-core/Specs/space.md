# Space

## Purpose

Geometry, tessellation, and field topology. Bridges between abstract node identities and spatial coordinates. Three layers: Tessellation → Field → concrete implementations.

## Layers

### Tessellation (trait)

Pure stateless geometry. Knows nothing about nodes or fields. Defines:
- `Point` — coordinate type for a tile (e.g. `SquarePoint { x, y }`)
- `Face` — a direction of transition between tiles (e.g. `SquareFace { N, S, E, W }`)
- `Size` — bounds descriptor (e.g. `SquareSize { width, height }`)

Methods:
- `step(point, face) -> Point` — move from a point through a face to the adjacent point
- `contains(size, point) -> bool` — whether a point is within the given bounds
- `faces() -> &'static [Face]` — all possible faces for this tessellation
- `all_points(size) -> Vec<Point>` — every point within the given size

### Field (trait)

A concrete spatial instance: tessellation + size + topology + NodeId↔Point mapping. Different implementations can have different topology (standard bounded, toroidal, irregular shape).

Methods:
- `node_count() -> usize`
- `neighbors(node) -> Vec<NodeId>` — topologically adjacent nodes (respects boundaries and topology)
- `node_at(point) -> Option<NodeId>`
- `point_of(node) -> Point`
- `build_graph(&mut IdGenerator) -> Graph` — generates NodeIds, populates mappings, creates Graph with nodes only (no edges)

### StandardField\<T: Tessellation\>

Default Field implementation for bounded rectangular-like fields. Internally:
- `size: T::Size`
- `point_to_node: HashMap<T::Point, NodeId>`
- `node_to_point: HashMap<NodeId, T::Point>`

`neighbors` implementation: iterate `T::faces()`, apply `T::step`, filter by `T::contains`, look up NodeId.

`build_graph` implementation: iterate `T::all_points(size)`, assign NodeId from IdGenerator, populate both HashMaps, call `graph.add_node(id)`.

For non-standard topologies (torus, irregular shapes) — implement `Field` directly instead of using `StandardField`.

## Concrete Implementations (MVP)

### SquareTessellation

- `Point = SquarePoint { x: i32, y: i32 }`
- `Face = SquareFace { N, S, E, W }`
- `Size = SquareSize { width: usize, height: usize }`
- `step`: N→y+1, S→y-1, E→x+1, W→x-1
- `contains`: `0 <= x < width && 0 <= y < height`

### SquareField

Type alias: `StandardField<SquareTessellation>`

## Invariants

- NodeIds in Field are generated by IdGenerator — not derived from coordinates.
- Field is the only place that knows the Point↔NodeId mapping.
- Graph does not know about Field or coordinates.
- `build_graph` must be called before `neighbors`, `node_at`, `point_of`.
